# RLMs Visualizer

An interactive visualizer for **Recursive Language Models (RLMs)** — a research paper by Alex L. Zhang, Tim Kraska, and Omar Khattab from MIT CSAIL.

[![Paper](https://img.shields.io/badge/Paper-arXiv:2512.24601-green)](https://arxiv.org/abs/2512.24601)
[![Demo](https://img.shields.io/badge/Demo-Live-success)](https://your-domain.vercel.app)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

## 🎯 What are RLMs?

Recursive Language Models (RLMs) introduce a paradigm where LLMs handle massive contexts through:

- **Recursive decomposition** of queries (not just calling themselves, but treating prompts as manipulable objects)
- **REPL environments** for orchestration (Python REPL where context lives as a variable)
- **Dynamic context chunking** and sub-query delegation (model decides adaptively how to split)
- **Near-infinite context** handling (100x beyond model context windows)
- **Better accuracy** even on tasks within normal context windows

> "Much like the switch in 2025 from language models to reasoning models, we think 2026 will be all about the switch to Recursive Language Models." — Alex Zhang

## ✨ Features

### 1. Interactive Recursion Tree
- Animated visualization of query decomposition
- Click nodes to see sub-queries
- Show recursive depth and context distribution
- Highlight active execution paths

### 2. REPL Simulator
- Step-through interface for REPL execution
- Show input → process → output at each step
- Visualize context management
- Play/pause controls with speed adjustment

### 3. Code Playground
- Pre-loaded with paper examples
- Monaco Editor with Python syntax highlighting
- Editable code with terminal-style output
- Full vs Simplified code views

### 4. Context Visualizer
- Heatmap of token distribution
- Visualize chunking strategy
- Show recursive processing flow
- Interactive chunk details

## 🎨 Design Philosophy

**Terminal Aesthetic** — The design follows a terminal-inspired look with:
- Deep black background (#0a0a0a)
- Terminal green (#22c55e) as primary accent
- Amber (#f59e0b) as secondary accent
- Monospace fonts (JetBrains Mono) throughout
- CRT scanline effects and blinking cursor animations

**Zero AI Fingerprint** — The design looks like it was crafted by MIT researchers, not generated by AI:
- Information-dense, academic aesthetic
- Mixed typography for hierarchy
- Purposeful animations (data flow, state transitions)
- Direct manipulation interactions

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router) with TypeScript
- **Styling**: Tailwind CSS with custom terminal theme
- **UI Components**: shadcn/ui (heavily customized)
- **Animations**: Framer Motion
- **Visualizations**: React Flow (tree diagrams)
- **Code Editor**: Monaco Editor (@monaco-editor/react)
- **State**: Zustand
- **Icons**: Lucide React
- **Fonts**: Geist (sans), JetBrains Mono (monospace)

## 🚀 Getting Started

- Node.js 18+ 
- npm or yarn


## 📊 Paper Insights

### Key Results

**OOLONG Benchmark (132k tokens)**
- RLM with GPT-5-mini outperforms GPT-5 by **110%+**
- More than double the performance
- Cheaper per query on average

**BrowseComp-Plus (1000 documents)**
- Only method maintaining perfect performance at scale
- Handles 10M+ tokens without degradation
- Outperforms ReAct + BM25 retrieval

### Core Concepts

1. **Recursive Decomposition**: Breaking queries into sub-queries with depth visualization
2. **REPL Environment**: Python notebook environment for context manipulation
3. **Context Chunking**: Dynamic partitioning with peeking, grepping, mapping strategies
4. **Sub-Query Delegation**: Using smaller models (GPT-5-mini) for recursive calls
