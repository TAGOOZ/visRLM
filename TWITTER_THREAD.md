## Engagement Strategy

### Reply Templates:

**When someone asks "What are RLMs?"**
```
Great question! RLMs = Recursive Language Models

Instead of feeding 10M tokens directly to an LLM (which would fail), the model:
1. Stores context in a Python REPL as a variable
2. Writes code to inspect/slice/decompose it
3. Recursively calls smaller models on chunks
4. Combines results

Think: Manager delegating tasks vs. doing everything alone
```

**When someone compliments the design**
```
Thanks! The goal was "zero AI fingerprint" — no generic gradients, glassmorphism, or startup tropes.

Wanted it to look like MIT researchers built it: information-dense, terminal aesthetic, purposeful animations only.
```
